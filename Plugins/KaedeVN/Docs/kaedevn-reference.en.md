# KaedeVN — Reference

This reference is for KaedeVN 0.2.0 (2026-10-21).

Every block of the novel editor, every KS script command, every check and every setting of KaedeVN, a plugin for making visual novels inside Unreal Engine. It covers only what works in UE; commands you can write in a script but that do nothing in UE are listed by name in §4.3.

- The steps from installing the plugin to running and packaging the sample are in the [Setup guide](kaedevn-guide.en.md). If you are new, start there.
- [日本語](kaedevn-reference.md)

> The editor currently uses Japanese labels. This reference gives each label as it appears, with its meaning in English.

## 1. How to read this reference

### 1.1 Opening the tools

- Novel editor: in the level editor menu, **Tools → KaedeVN → KaedeVN ノベルエディタ** (novel editor). It works whichever map is open.
- KS script editor: **Tools → KaedeVN → KaedeVN KS台本エディタ** (KS script editor), or double-click a *KaedeVN KS台本プロジェクト* (KS script project) asset in the Content Browser.
- Project settings: **Edit → Project Settings → Plugins → KaedeVN** (§7.1).

### 1.2 Terms

| Term | Meaning |
|---|---|
| Work | One visual novel: one folder `works/<work id>/` in the work data folder (`WorkRoot`, §7.1) |
| Chapter | A folder inside the work (such as `01_第1章`). Their order is `chapters` in `work.json` |
| Episode | One file inside a chapter (`01_枯れた泉.json`), holding a list of blocks |
| Block | One piece you place in the novel editor (a line, a background, a character, a branch and so on; §3) |
| KS script | A text script (`.ks`) with one command or line of text per line (§4) |
| KSC | A small script language you can use alongside KS (`.ksc`; §4.4) |
| Op | One instruction in the `scenario.json` that a build produces. The game plays these in order |
| Asset id | A name for an image. `assets.json` maps each id to an image file |

### 1.3 How to read the tables

- The tables in §3–§7 are generated by a script from the sources (the plugin's source code and the bundled compiler). Their items and names match this version of the plugin.
- "Field" columns show the label as it appears in the editor (currently in Japanese).
- "Op" shows the Op that a block or command produces in the build. It helps when you look into `scenario.json` to find out why something does not work.
- In command syntax, `<…>` is a value you write and `[…]` may be left out. An argument written `fade=500` can also be written `fade 500`, separated by a space.

## 2. The novel editor

### 2.1 The four panes

| Pane | What it holds |
|---|---|
| ① Left | The tree of **chapters (folders) → episodes (files)**. Right-click to add, rename or delete chapters and episodes |
| ② Middle | The **blocks** of the selected episode |
| ③ Top right | The **fields** of the selected block (§3) |
| ④ Bottom right | The **preview** (redrawn as soon as you edit a field) |

The top row holds the work selector (作品:, "work"), the screen size of the work (解像度:, "resolution": `720p` or `1080p`) and the buttons.

![The four panes of the novel editor (a line of the sample episode selected)](images/kaedevn/editor-novel.png)


### 2.2 Buttons and keys

| Button / key | What it does |
|---|---|
| 新規 (New) | Creates a work (enter its title) |
| 見本を置く (Place sample) | Copies the bundled sample work *枯れた泉の守り人* into the work data folder and opens it. Existing files are not overwritten (only ids that are missing are added to `assets.json`) |
| ＋ブロック (+ Block) | Adds a block after the selected one. If the selection is an `if`, a `choice` or an option, the block goes inside it |
| 複製・削除・↑・↓ (Duplicate, Delete, Up, Down) | Copies, deletes or reorders blocks |
| ↶・↷ (Ctrl+Z, Ctrl+Y) | Undo and redo. The history is per episode and is cleared when you open another episode |
| 保存 (Save, Ctrl+S) | Saves the episode, and also writes a KS script (`.ks`) and KSC (`.ksc`) with the same content next to it |
| ビルド (Build) | Compiles the whole work (chapter order, then episode order) into `works/<work id>/scenario.json` and runs the checks (§6.1) |
| ▶ プレイ (Play) | Builds, then plays in PIE. The map is the `PreviewMap` setting (or the open map if it is empty) |

Build check findings appear in the list at the bottom. Click a row to open that episode and select that block.

Shows a choice. It holds options, and each option holds the blocks that run after it is chosen.

## 4. KS scripts

A KS script is a text script with one file per episode. When you save in the novel editor, a `.ks` with the same content is written from the blocks. You can also write it directly in the KS script editor (§5).

```
; title: 枯れた泉
*start
@bg forest fade=500
#ナレーション
ルカは、いつもの足取りで村の中央にある泉へと向かっていた。
@l
@ch luca default center
#ルカ
……泉が、枯れている。
@p
@jump next
```

### 4.1 Line types

<!-- kaedevn-ref:begin ks-lines -->
| Line type | How to write | What it does |
|---|---|---|
| `COMMENT` | `; メモ`・`// メモ` | A comment, not shown in the game. A leading `; title: <title>` becomes the episode title. |
| `COMMAND` | `@bg forest` | A command: `@`, the command name and its arguments (§4.2). An unknown name is a build error. |
| `TEXT` | `泉が、枯れている。` | Text, shown as a line of the current speaker. You may also write the speaker before a full-width colon, as in `Name：line`. |
| `VAR_SET` | `trust = 1`・`trust += 1`・`trust -= 1` | Sets, adds to or subtracts from a variable. `=` takes a number, a `"string"` or `true`/`false`; `+=` and `-=` take numbers only. |
| `CHOICE_START` | `choice {` | Starts a choice. List the options inside and close it with `}`. |
| `CHOICE_OPTION` | `"一緒に行く" {` | One option. The quoted text becomes a button; choosing it runs the lines from `{` to `}`. An `if (…)` condition does not work yet (you get a warning and the option is always shown). |
| `CHOICE_END` | `}` | Closes a choice, an option or an `if` block. |
| `IF_START` | `if (trust >= 2) {` | Branches on a condition: `variable` (when true), `variable == number` (`!=`, `>=`, `<=`, `>`, `<`), `&&`, `\|\|`, `!`, `( )`. |
| `IF_ELSE` | `} else {` | The branch taken when the condition is false. |
| `IF_END` | `}` | Closes an `if` (written `}` like `CHOICE_END`; which one it closes depends on where it is). |
| `LABEL` | `*start` | A label, the target of `@jump` and `@call`. Names are kept per episode (file), and other episodes can jump to them. |
| `SPEAKER` | `#ルカ`・`#` | Speaker. The following text lines are spoken by this name. A bare `#` clears the speaker (narration). |
<!-- kaedevn-ref:end ks-lines -->

#### `@bg`

Changes the background. A bare `@bg` with no id clears the background (`BG_CLEAR`).

Syntax: `@bg <id> [fade=<ms>|slide_left=<ms>|slide_right=<ms>] [x=<n>] [y=<n>] [s=<scale>]`

| Argument | In UE | What to write |
|---|---|---|
| `id` | Works | The background asset id (a key in `assets.json`). |
| `fade` | Works | Cross-fade from the previous background, in milliseconds. |
| `slide_left` | No effect | Slide to the left while changing. In UE it does not slide; it cross-fades over the given milliseconds. |
| `slide_right` | No effect | Slide to the right while changing. In UE it does not slide; it cross-fades over the given milliseconds. |
| `x` | No effect | Horizontal offset. No effect in UE. |
| `y` | No effect | Vertical offset. No effect in UE. |
| `s` | No effect | Scale. No effect in UE. |

Example:

```
@bg forest fade=500
@bg
```

Op: `BG_SET`, `BG_CLEAR`

#### `@ch`

Shows a character sprite. If the same character is already shown, its pose and position are replaced.

Syntax: `@ch <name> <pose> <pos> [fade=<ms>] [x=<n>] [y=<n>] [s=<scale>]`

| Argument | In UE | What to write |
|---|---|---|
| `name` | Works | The character asset id (a key in `assets.json`). |
| `pose` | Works | The pose name (`default` in the sample). |
| `pos` | Works | Position: `left`, `center` or `right` (or the single letters `L`, `C`, `R`). |
| `fade` | Works | Fade-in time in milliseconds. |
| `x` | No effect | Horizontal offset. No effect in UE (the position decides it). |
| `y` | No effect | Vertical offset. No effect in UE. |
| `s` | No effect | Scale. No effect in UE. |

Example:

```
@ch luca default center fade=300
```

Op: `CH_SET`

#### `@timeline_play`

## 5. The KS script editor

### 5.1 The screen

The KS script editor shows the lines of a script as a tree, next to the fields of the selected line, a preview and the checks (§6.2).

- There are six line kinds: empty, comment (`;`), label (`*`), tag (an `@` command), speaker (`#`) and text.
- Text and speaker lines have their own fields. Tag lines get dedicated fields for the tags in the table below; other tags, labels and comments are edited as one line in the 行テキスト ("line text") field.
- Editing a field keeps the other arguments of that line (unknown `key=value` pairs are not lost). The editor never touches other lines or their formatting (the text files are the source of truth).
- ＋行追加 (add line), 行削除 (delete line), ↑, ↓, ＋ページ (add page), ページ削除 (delete page), 保存 (save) and ビルド (build: compiles to `scenario.json` with `kaedevn-ks-compile.exe`).

![The KS script editor: the script tree on the left (the error mark on the added line `@bg bg_typo` is an example), the preview in the middle and the fields of the selected line on the right](images/kaedevn/editor-ks.png)

## 8. Packaging

- The game is hosted by the GameInstance, GameMode and PlayerController of the `KaedeVnHost` module. Even in a project that sets no GameInstance, setting the GameMode to `KaedeVnGameMode` makes its PlayerController put the novel on screen. The plugin binds the controls (advance, choose, back, auto, skip, quick save / load, menu) with Enhanced Input.
- Stage the work data folder (`WorkRoot`, §7.1) as UFS. For the default `Game`, add `+DirectoriesToAlwaysStageAsUFS=(Path="../Game")` under `[/Script/UnrealEd.ProjectPackagingSettings]` in your project's `Config/DefaultGame.ini`. Without this line the packaged game starts but finds no scenarios.
- Add `-nodebuginfo` to the packaging command (RunUAT BuildCookRun). Without it the PDB goes into the archive and makes it larger.
- The archive folder is not emptied between runs. Empty `Saved/Package` and `Saved/StagedBuilds` before you measure the size.
- A packaged game writes its logs and saves to `%LOCALAPPDATA%\<ProjectName>\Saved`, not next to the `.exe`.

## 9. Modules and files

| Module | Type | What it does |
|---|---|---|
| `KaedeVnCore` | Runtime | Playback (runs the Ops in order; save and load). Separate from rendering, with automated tests |
| `KaedeKsc` | Runtime | A small VM that runs KSC, and its UE host |
| `KaedeVnUI` | Runtime | Draws the novel screens (on top of MomijiUI) |
| `KaedeVnHost` | Runtime | GameInstance, GameMode and PlayerController for a packaged novel |
| `KaedeShaders` | Runtime (PostConfigInit) | The shader directory `/Kaede` |
| `KaedeVnEditor` | Editor | The novel editor and the KS script editor. Windows editor only |

Bundled executables (`ThirdParty/Win64/`; none of them uses the network; their origin and how to rebuild them are in `ThirdParty/Win64/README.md`, and `SHA256SUMS.txt` lets you verify them):

| Executable | When it is used |
|---|---|
| `kaedevn-ks-compile.exe` | Build in the KS script editor: links the `.ks` files into `scenario.json` |
| `kaedevn-blocks2ks.exe` | Save in the novel editor: writes `.ks` and `.ksc` from the episode's blocks |
| `kaedevn-ksc-service.exe` | Compiles KSC commands inside the game |

Screens and fonts come from the MomijiUI plugin (a free product on Fab; KaedeVN's `.uplugin` enables it).

## 10. Not yet supported

- Authoring works only in the Windows editor (not in the Mac or Linux editor).
- The editor's labels are in Japanese. The English edition of this reference explains each label in English.
- The commands in §4.3 do nothing in UE. They include the music, sound effect and voice commands: the UE player does not play sound yet (the music name goes into saves, but nothing plays).
- Even for the commands in §4.2, arguments marked "No effect" in their tables are not used in UE (offset and scale of backgrounds and characters, sliding background changes, fading when a character is hidden, and so on).
- Of the config screen items, the UE game applies only those marked "Yes" in the table in §7.3.
- Conditions on KS choice options (`"…" if (…) {`) do not work yet.
