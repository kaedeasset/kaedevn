この説明書は KaedeVN 0.2.0（2026-10-21）のものです。

- 版ごとに何が変わったかは、[更新履歴](kaedevn-changelog.md)にあります。

## 1. はじめての一本道（入れてから書き出すまで）

UE（Unreal Engine）で KaedeVN を初めて使う人が、Fab で入れてから見本の作品を書き出すまでの順番です。上から順に進めれば、ほかの章を読まずに最後まで行けます。ほかの章は、自分の作品を作るときに、必要な所だけ読んでください。

**先に全体の順番です。** KaedeVN は単独で起動するアプリではなく、UE のエディタの中で動く道具です。なので「KaedeVN を起動する」という手順はありません。UE でプロジェクトを開き、メニューからノベルエディタを開きます（1.5）。このガイドでは、プログラムを立ち上げることを「起動する」（ランチャー・UE・書き出したゲーム）、動いているプログラムの中で窓や作品を出すことを「開く」（プロジェクト・ノベルエディタ・作品）と書き分けます。

| 順 | やること | どこで | 終わると |
|---|---|---|---|
| 1.1 | Fab で KaedeVN と MomijiUI を入れる | Fab とランチャー | UE に KaedeVN と MomijiUI が入る |
| 1.2 | UE 5.8 と Visual Studio を入れる | ランチャーと Microsoft のインストーラー | プロジェクトを作る準備が整う |
| 1.3 | C++ のプロジェクトを作り、KaedeVN を有効にする | UE のプロジェクトブラウザとエディタ | KaedeVN の入ったプロジェクトが開く |
| 1.4 | 見本の作品を置く | ノベルエディタ | 見本「枯れた泉の守り人」が開く |
| 1.5 | ノベルエディタの画面を知る | ノベルエディタ | 4 つの区画の役目が分かる |
| 1.6 | 台詞を 1 行直して保存する | ノベルエディタ | 話のファイルが書き換わる |
| 1.7 | ビルドして ▶ プレイ | ノベルエディタ | エディタの中で見本を遊べる |
| 1.8 | 指摘が出たら直す | ノベルエディタ | 指摘が 0 件になる |
| 1.9 | 書き出す（パッケージ化） | UE のエディタ | Windows の exe ができる |

2 回目からは、1.3 で作ったプロジェクトを開き、**Tools → KaedeVN → KaedeVN ノベルエディタ**（1.5）だけを行います。1.1〜1.4 は最初の 1 回だけです。

### 1.1 Fab で KaedeVN と MomijiUI を入れる

KaedeVN は画面の描画に、もう 1 つの無料のプラグイン **MomijiUI** を使います。2 つとも入れます。

1. Epic Games のアカウントで Fab（fab.com）にサインインし、KaedeVN のページで「ライブラリに追加」します。MomijiUI も同じようにします。どちらも無料です。
2. Epic Games Launcher（ランチャー）の **Unreal Engine → ライブラリ** の Fab の欄に 2 つが並びます。それぞれ **エンジンにインストール** を押し、**5.8** を選びます。プラグインは `<UE のフォルダ>\Engine\Plugins\Marketplace\` の下に入ります。

UE 5.8 がまだ入っていなければ、先に 1.2 の手順 1 を済ませてから戻ってください。

### 1.2 UE 5.8 と Visual Studio を入れる

1. ランチャーの **Unreal Engine → ライブラリ** で、エンジンのバージョンの **＋** を押し、**5.8** を選んで **インストール** します。
2. Microsoft のサイトから **Visual Studio Community**（無料）のインストーラーを取ってきて起動し、ワークロードの **C++ によるゲーム開発** に印を付けて入れます。版は **2022 の最新（17.14）か 2026 の最新**にします（UE 5.8 は、古い版の一部〔2022 の 17.13 以前・2026 の初めの版〕を組み立てに使いません。もう入っているなら Visual Studio Installer の **更新** を押します）。KaedeVN は C++ のプラグインなので、プロジェクトを C++ で作り（1.3）、書き出すときもこのプラグインのコードをゲームに組み込みます（1.9）。そのために要ります。

### 1.3 C++ のプロジェクトを作り、KaedeVN を有効にする

1. ランチャーで 5.8 の **起動** を押します。
2. プロジェクトブラウザで **ゲーム → 空のプロジェクト**（Blank）を選び、**C++** を選びます。プロジェクトの名前は**英数字と `_` だけ**（例 `MyNovel`）にして **作成** を押します。Visual Studio がプロジェクトのコードを組み立て、エディタが開きます。
3. エディタの **編集 → プラグイン** で **KaedeVN** を探し、印を付けて有効にします。KaedeVN に要る MomijiUI も有効にするかを聞く窓が出たら **はい** を押します。
4. 「再起動が必要」と出るので、エディタを開き直します。同じプロジェクトを開きます。

プラグインはエンジンに入っただけでは使えず、プロジェクトごとに有効にします。有効にするのは、プロジェクトを作った最初の 1 回だけです。

### 1.4 見本の作品を置く

1. メニュー **Tools → KaedeVN → KaedeVN ノベルエディタ**（日本語の表示では **ツール**）を選びます。ノベルエディタがタブで開きます。どのマップを開いていても使えます。
2. 上の段の **見本を置く** を押します。プラグインに入っている見本の作品「枯れた泉の守り人」（1 章 1 話）が、プロジェクトの `Game` フォルダ（作品の置き場。§4）へ写され、開きます。前からあるファイルは上書きしません。
3. 左上の **作品:** の欄に **枯れた泉の守り人** が出ていれば、置けています。

### 1.5 ノベルエディタの画面を知る

ノベルエディタは 4 つの区画に分かれています。

| 区画 | 何があるか |
|---|---|
| ① 左 | 作品の中の **章（フォルダ）→ 話（ファイル）** の木 |
| ② 中 | 選んだ話の **ブロックの列**（台詞・背景・立ち絵・分岐など） |
| ③ 右上 | 選んだブロックの **欄** |
| ④ 右下 | **プレビュー**（欄を直すとすぐ描き直す） |

① で章「01_第1章」を開き、話「01_枯れた泉」を選ぶと、② にブロックが並びます。

![ノベルエディタ。① 章と話の木・② ブロックの列（台詞を選んだ所）・③ 欄・④ プレビュー](images/kaedevn/editor-novel.png)

### 1.6 台詞を 1 行直して保存する

1. ② で `text` のブロック（台詞）を 1 つ選びます。
2. ③ の **本文** を書き換えます。④ のプレビューがすぐ変わります。**話者(空=地の文)** の欄は、台詞を言う人の名前です。
3. **Ctrl+S**（または **保存**）で保存します。話のファイル（`.json`）と一緒に、同じ中身の文字の台本（`.ks`・`.ksc`）も同じフォルダに書かれます。

ブロックは **＋ブロック** で足せます（選んだブロックの次に足します）。足せるのは、台詞（`text`）・背景（`bg`）・立ち絵（`ch`）・変数（`set_var`）・ジャンプ（`jump`）・条件分岐（`if`）・選択肢（`choice`）の 7 種です。**Ctrl+Z**／**Ctrl+Y** で元に戻す・やり直すができます。

### 1.7 ビルドして ▶ プレイ

1. **ビルド** を押します。作品全部（章の順 → 話の順）が `Game/works/fantasy_block_demo/scenario.json` に組まれ、検査が回ります。
2. **▶ プレイ** を押します。ビルドしてから、エディタの中（PIE）で見本が始まります。マップは今開いているマップのままで構いません。
3. タイトル画面の **はじめる** を押し、クリック・**Enter**・**Space** で読み進めます（見本は背景・立ち絵・台詞 4 つの短い 1 話です）。1.6 で直した台詞が出ることを確かめたら、エディタのツールバーの **停止**（■）で戻ります。

![見本を遊んでいる所。背景・立ち絵・名前の窓と本文](images/kaedevn/play.png)

### 1.8 指摘が出たら直す

ビルドは、「組めるのに遊ぶとおかしくなる所」を検査します（素材が無い・本文が空・飛び先の話が無い など 15 種）。見つかったものはノベルエディタの下に一覧で出ます。**行を押すと、その話を開いてそのブロックを選びます。** ③ の欄を直して、もう一度 **ビルド** します。指摘はビルドを止めません。見本のままなら指摘は 0 件です。

![ビルドの指摘の一覧。見本の写しに誤りを 2 つ（背景の id の打ち間違い・空の本文）入れてビルドし、1 つ目の指摘を押してそのブロックを選んだ所](images/kaedevn/editor-build-checks.png)

### 1.9 書き出す（パッケージ化）

エディタの中で遊べたら、Windows のゲームとして書き出します。設定は最初の 1 回だけです。

1. **ゲームのマップを作る**: **ファイル → 新規レベル → 空のレベル** を選び、**ファイル → 現在のレベルを保存** で `Content` の下に保存します（例 `NovelMap`）。
2. **ゲームの土台を KaedeVN にする**: **編集 → プロジェクト設定 → マップ & モード** で、**デフォルトの GameMode** を `KaedeVnGameMode` に、**ゲームのデフォルトマップ** を手順 1 のマップにします。ノベルの画面と操作（キーボード・マウス・ゲームパッド）は、この GameMode がつなぎます。
3. **作品の置き場をゲームに入れる**: プロジェクトのフォルダの `Config/DefaultGame.ini` をメモ帳で開き、末尾に次の 2 行を足して保存します。この行が無いと、書き出したゲームは起動しても台本が見つかりません。

   ```ini
   [/Script/UnrealEd.ProjectPackagingSettings]
   +DirectoriesToAlwaysStageAsUFS=(Path="../Game")
   ```

4. **起動する作品を決める**: プロジェクトのフォルダの `Game` に `projects` というフォルダを作り、その中に `projects.json` を次の中身で作ります（文字コードは UTF-8）。書き出したゲームは、この一覧の先頭の作品を遊びます。

   ```json
   {
     "projects": [
       { "id": "fantasy_block_demo", "title": "枯れた泉の守り人", "scenario": "works/fantasy_block_demo/scenario.json" }
     ]
   }
   ```

5. ノベルエディタで **ビルド** をもう一度押し、`scenario.json` を新しくします。
6. **プラットフォーム → Windows → プロジェクトをパッケージ化** で、出力先のフォルダを選びます。配る版にするときは、同じメニューのパッケージ化の構成を **Shipping** にします。Visual Studio がこのプラグインのコードをゲームに組み込みます。
7. 出来たフォルダの exe を起動すると、見本のタイトル画面から始まります。

書き出したゲームのログとセーブは、exe の隣でなく `%LOCALAPPDATA%\<プロジェクトの名前>\Saved` に書かれます。

自分の作品は、ノベルエディタの **作品を新規作成** で作り、1.6〜1.9 と同じ順で直して遊んで書き出します（手順 4 の一覧の id・題・`scenario` を自分の作品に替えます）。

## 2. このプラグインでできること

**UE で動くものだけを書いています。** 台本に書けても UE ではまだ何もしない命令は §7 にあります。

| 分野 | できること |
|---|---|
| ノベルエディタ | 作品 › 章 › 話 › ブロックで組む。ブロックは 7 種（台詞・背景・立ち絵・変数・ジャンプ・条件分岐・選択肢）。欄を直すとすぐ描き直すプレビュー。元に戻す／やり直す（話ごと）。章はフォルダ・話はファイルなので、エディタの外でも並びが読める。作品の画面の大きさ（720p・1080p） |
| ビルドの検査 | 組めるのに遊ぶとおかしくなる所を 15 種知らせる（素材が無い・本文や選択肢の文が空・飛び先の話が無い・id の重なり など）。行を押すとそのブロックへ移る。ビルドは止めない |
| KS 台本 | 1 話 1 ファイルの文字の台本（`.ks`）。命令・台詞・話者・ラベル・変数・選択肢・条件分岐を書ける。ノベルエディタの保存でも同じ中身の `.ks` が書かれる |
| KS 台本エディタ | 台本の行を木で見せ、選んだ行の欄・プレビュー・検査（8 種）を並べる。KS 台本エディタは文字を書き換えない（KS で書いた台本の正は文字のファイル） |
| 同梱のコンパイラ | KS 台本エディタのビルドが使う `kaedevn-ks-compile.exe`（KS 台本 → `scenario.json`）と、ノベルエディタの保存が使う `kaedevn-blocks2ks.exe`（ブロック → KS の文字）。外の道具は要らず、ネットワークに出ない。ノベルエディタのブロックはエディタ自身が `scenario.json` に組む |
| 絵の演出 | 背景（溶けこみ）・立ち絵（3 つの立ち位置・表情の差し替え・移動）・スプライト（好きな位置の絵を動かす・透かす・拡大する）・決めた位置の文字・重ね絵（雨・霧・枠など）・レイヤを隠す・透かす・切り替えの溶けこみ |
| 画面の演出 | 色のフィルタ・揺れ・フラッシュ・暗転と明け（黒・白）・1 色の幕・カメラ（寄る・ずらす）・タイムライン（複数の動きを時間に沿って並べた演出） |
| 流れ | 台詞と地の文・文字送り・改行と改ページ・クリック待ち・時間の待ち・選択肢・変数と条件分岐・ジャンプ・呼び出しと戻り・KSC（台本の中の小さなスクリプト。旗・持ち物の数・計算） |
| ゲームの画面 | タイトル・メニュー・目次・セーブ・ロード・解説書・コンフィグ（見本の 7 枚。どれも MomijiUI の JSON なので、作品ごとに直せる）。オート・スキップ・クイックセーブ／ロード。コンフィグのうち UE が反映するのは、文字の速さ・書体・窓の大きさ・配色の 4 項目 |
| 操作 | キーボード・マウス・ゲームパッド（§5）。プラグインが Enhanced Input で割り当てるので、プロジェクトでつなぐことは無い |
| 書き出し | Windows のゲーム。ゲームの土台（GameInstance・GameMode・PlayerController）はプラグインの `KaedeVnHost` |

作品は**作品の置き場**の JSON と文字の台本です（§4）。Git で差分を見られます。

## 3. 要るもの

- Unreal Engine 5.8・Windows（64 bit）
- **Visual Studio 2022 の最新（17.14）か Visual Studio 2026 の最新** と、ワークロード **C++ によるゲーム開発**（C++ のプロジェクトを作るときと、書き出すとき。§1.2）
- **MomijiUI**（無料のプラグイン。Fab の別の商品。KaedeVN を有効にすると一緒に有効になる）

## 4. 作品のフォルダ

KaedeVN は、作品のデータを 1 つのフォルダ（**作品の置き場**）から読みます。場所は **編集 → プロジェクト設定 → Plugins → KaedeVN** の `WorkRoot` で、既定は `Game`（プロジェクトのフォルダの直下）です。

| 場所 | 中身 |
|---|---|
| `works/<作品の id>/work.json` | 作品の題と、章の並び |
| `works/<作品の id>/<章のフォルダ>/<話>.json` | 話のブロックの列。保存すると、隣に同じ中身の `.ks`・`.ksc` も書かれる |
| `works/<作品の id>/scenario.json` | ビルドの出力。ゲームはこれを再生する（手で直さない） |
| `ui/` | ゲームの画面（MomijiUI の JSON。タイトル・メニュー・目次・セーブ・ロード・解説書・コンフィグ） |
| `assets.json` | 絵の id → 絵のファイル。ブロックや台本は絵を id で指す |
| `assets/` | 絵のファイル（見本は背景 2 枚・立ち絵 2 枚） |
| `projects/projects.json` | 書き出したゲームが遊ぶ作品の一覧（§1.9 の手順 4） |

- 書き出すときは、このフォルダを丸ごとゲームに入れます（§1.9 の手順 3 の行。`WorkRoot` を替えたら `Path` も同じ場所に）。
- 絵を足すときは、絵のファイルを `assets/` に置き、`assets.json` に `"<id>": "<プロジェクトのフォルダからの道>"` の 1 行を足します。

## 6. テキストで書く（KS 台本）

ノベルエディタで組む代わりに、文字の台本（KS 台本）で書くこともできます。1 話を 1 つの `.ks` ファイルにし、1 行に 1 つ、命令か台詞を書きます。

```
; title: 枯れた泉
@bg forest
#ナレーション
ルカは、いつもの足取りで村の中央にある泉へと向かっていた。
@l
#ルカ
……泉が、枯れている。
@p
@jump next
```

| 行 | 意味 |
|---|---|
| `; …` | 注釈（ゲームには出ない）。先頭の `; title:` は話の題 |
| `@bg forest` | 背景を `assets.json` の id `forest` の絵に替える |
| `#ルカ` | 続く本文を「ルカ」の台詞にする（`#` だけなら地の文） |
| 本文の行 | 台詞・地の文 |
| `@l`・`@p` | クリックを待つ（`@p` は本文を消して次のページへ） |
| `@jump next` | ラベル `*next` へ飛ぶ |

KS 台本は **Tools → KaedeVN → KaedeVN KS台本エディタ** で、行を木で見ながら直せます。このメニューは、プロジェクトの中の「KaedeVN KS台本プロジェクト」のアセット（台本のフォルダを指すデータアセット）を開きます。Fab で入れたばかりのプロジェクトにはこのアセットが無いので、「KaedeVN 台本プロジェクトが見つかりません」と出て何も開きません（§7）。いまは、ノベルエディタで組んで保存すると書かれる `.ks` を、文字の形として読む・写す使い方が確かです。命令の全部と引数は[リファレンス](kaedevn-reference.ja.md)の §4、KS 台本エディタは §5 にあります。

## 7. まだできないこと

- 作るのは Windows のエディタだけです（Mac・Linux のエディタでは作れません）。書き出すゲームも、確かめているのは Windows です。
- **エディタの表示は、いまは日本語です。** このガイドの英語版とリファレンスの英語版に、欄の名前の英語の意味を添えています。
- **音はまだ鳴りません。** BGM・効果音・声の命令は台本に書けてビルドも通りますが、UE のゲームでは何もしません。Live2D・VRM・粒子・RPG のマップの命令も同じです（命令の名前の一覧はリファレンスの §4.3）。
- コンフィグの画面の項目のうち、UE のゲームが反映するのは、文字の速さ・書体・窓の大きさ・配色の 4 つです。ほかは画面で選べますが、まだ使いません。
- KS 台本の選択肢の条件（`"…" if (…) {`）はまだ効きません（いつも出ます）。
- KS 台本エディタを開くアセット（KaedeVN KS台本プロジェクト）を作るボタンは、まだありません。KS 台本だけで作品を始める手順も、まだこのガイドにありません（§6）。
- ノベルエディタのブロックは 7 種です。画面のフィルタ・重ね絵・揺れなどの演出は、KS 台本で書きます（§6）。

## 8. 困ったとき

| こんなとき | 見るところ |
|---|---|
| メニューに「KaedeVN」が無い | プラグインが有効か（**編集 → プラグイン**）。有効にしたらエディタを開き直す（§1.3） |
| 「見本を置く」で作品が出ない | 作品の置き場（`WorkRoot`）に書けるか。プロジェクトのフォルダの `Game/works/fantasy_block_demo/` ができているか |
| 絵が出ない | 素材の id が `assets.json` にあるか・その道に絵があるか（ビルドの検査が「アセットが見つかりません」と知らせる） |
| ▶ プレイで何も始まらない・別の画面が出る | ビルドが「ビルド失敗」になっていないか（上の段の文）。設定の `PreviewMap` に、自分の GameMode を決めたマップを入れていないか（空なら今開いているマップで KaedeVN が遊ぶ） |
| 書き出したゲームで台本が無い・見本でないデモが始まる | `Config/DefaultGame.ini` の UFS の行（§1.9 の手順 3）と、`Game/projects/projects.json`（手順 4）。どちらも直したら、もう一度パッケージ化する |
| 書き出したゲームで操作が効かない・ノベルが出ない | **デフォルトの GameMode** が `KaedeVnGameMode` か（§1.9 の手順 2） |
| 書き出しで「コードを組み立てられない」 | Visual Studio とワークロード **C++ によるゲーム開発** が入っているか（§1.2） |
| ログ・セーブを見たい | 書き出したゲームは `%LOCALAPPDATA%\<プロジェクトの名前>\Saved`。エディタはプロジェクトの `Saved/Logs` |
| ビルドの検査の文の意味が分からない | リファレンスの §6.1 に、出る文ごとの意味と直し方がある |
