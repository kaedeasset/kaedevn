# KaedeRPG イベントコマンド統合設計・引き継ぎ資料

更新日: 2026-10-23
状態: 設計提案（実装未確定）

## 目的
UE5製RPG制作ツール KaedeRPG において、既存 KaedeVN のティラノスクリプト型コマンドを活用し、テキスト編集とWOLF RPGエディター型のGUIフルコマンド編集を両立させる。イベント実行系を二重実装しない。

## リポジトリで確認済みの事実
- KaedeVN は UE5.8 向けのノベルエンジン。
- `Plugins/KaedeVN/` に `KaedeVnCore`（エンジン非依存のセッション）、`KaedeKsc`（KSC VM）、`KaedeVnUI`（Slate）、`KaedeVnHost`、`KaedeShaders` がある。
- `Tools/kaedevn-compiler/` は KS/KSC を `scenario.json`（Op IR）に変換する TypeScript コンパイラ。
- GUIノベルエディターとKSスクリプトエディターはこの公開リポジトリに含まれず、Fab等で配布される。
- KaedeRPG は KaedeVN を組み込むRPG制作ツールとしてREADMEに記載されている。
- MomijiUI は別リポジトリで管理される。

参照: https://github.com/kaedeasset/kaedevn/blob/main/README.md

## 基本方針
1. **既存VM・IRを優先**。新しいイベントVMは作らず、既存命令体系の拡張可能性を調査する。
2. **入力方法は2種類**。KS/KSCのテキスト編集と、コマンドを選んで引数を設定するGUI編集。
3. **実行形式は共通**。どちらの入力も、可能な範囲で既存コンパイラ経由のOp IRへ変換する。
4. **機能拡張はホスト側へ分離**。RPGのマップ移動、戦闘、所持品、クエスト等の実行は適切なホストAPIへ委譲し、ノベルエンジンへの密結合を避ける。
5. **GUIは宣言的**。MomijiUIのJSON UI定義を再利用できるか調査する。

## 想定構成
```text
KS/KSC テキスト編集 ──> 既存コンパイラ ──┐
                                          ├─> 既存 Op IR ─> KaedeKsc / KaedeVnCore
GUI フルコマンド編集 ─> GUIモデル/変換層 ─┘                         │
                                                        RPGホストAPI
                                                        ├─ マップ
                                                        ├─ 戦闘
                                                        ├─ アイテム/変数
                                                        └─ オンライン機能（将来）
```
※GUIモデルからIRへ直接変換するか、KS/KSCテキストを生成して既存コンパイラを経由するかは未決定。既存IR仕様を確認してから選択する。

## GUIイベントエディター案
- 命令追加・削除・複製・並べ替え
- 命令別パラメータフォーム（型、候補、入力制約）
- 条件分岐・ループ・選択肢の階層表示
- コモンイベント呼び出し、検索、参照ジャンプ
- 検証エラー表示と実行位置の可視化
- テキスト表示/編集への切り替え

最初から任意のKS/KSCをGUIに完全逆変換することは約束しない。コメント・未知の命令・式・ラベル・制御フローの保持を検証し、非対応構文は読み取り専用表示またはテキスト編集へ誘導する。無損失往復変換は独立した受け入れ条件とする。

## コマンド分類（提案）
| 分類 | 例 |
|---|---|
| ノベル | メッセージ、立ち絵、背景、選択肢 |
| 制御 | 変数、条件分岐、ループ、ジャンプ、共通処理 |
| マップ | 移動、ワープ、イベント発火 |
| RPG | 戦闘開始、アイテム、経験値、状態異常 |
| UI | ウィンドウ、メニュー、テーマ |
| ネットワーク（後期） | ランキング、サーバーAPI |

命令名やJSONスキーマは既存実装の調査後に確定する。上表は既存対応機能の一覧ではない。

## 実装順序
1. KaedeVNのKS/KSC文法、Op IR、VM、ホストAPI、既存テストを調査。
2. KaedeRPG本体の実装とイベント処理との接続箇所を確認（本リポジトリだけでは未確認）。
3. 既存命令と不足するRPG命令の対応表を作成。
4. 小さなGUI試作：文章表示、変数操作、条件分岐、選択肢。
5. GUI→実行IRの変換とテストを実装。
6. RPG用コマンド、デバッグ、編集支援を段階的に追加。
7. AI生成は既存の構文・IRバリデータを通して取り込む。

## テスト/受け入れ基準
- 同等のテキスト入力とGUI入力が同じイベント動作になる。
- 分岐、変数、選択肢、ジャンプ、セーブ/ロードを回帰テストする。
- 不正引数や未知命令はクラッシュさせず診断する。
- GUI編集後の保存・再読込で意味が変わらない。
- 既存のKaedeVNサンプルと自動テストが引き続き成功する。
- GUIに未対応の構文を黙って破棄しない。

## Claude Codeへの引き継ぎ
最初に `README.md`、`Plugins/KaedeVN/Docs/kaedevn-reference.md`、`Plugins/KaedeVN/Docs/kaedevn-guide.md`、`Tools/kaedevn-compiler/`、`Plugins/KaedeVN/` を調べ、実在するクラス・Op型・変換処理を列挙すること。既存IR/VMの拡張点を特定するまで新しいIR/VMを実装しないこと。KaedeRPG本体のソースが見つからない場合はその旨を明記し、推測でコードを変更しないこと。
