# Sample Asset Licenses / サンプル素材のライセンス

This file covers the sample game data under `Game/` shipped with the KaedeVN
sample project ("枯れた泉の守り人" / "選択の結果" and the KS sample).

## Images (backgrounds, character sprites, title, UI icons)

- Files: `Game/assets/bg/`, `Game/assets/ch/`, `Game/assets/generated/`,
  `Game/assets/title/`, `Game/ui/shared/icons/`
- Provenance: **All images were generated with Midjourney** by the project
  author (kaedeasset) under a paid Midjourney subscription, which grants ownership
  and commercial-use rights to the subscriber (Midjourney Terms of Service;
  ownership persists after subscription changes).
- Grant: To the extent the author holds any rights in these images, they are
  dedicated to the public domain under **CC0 1.0 Universal**. Note that
  purely AI-generated content may not be protected by copyright in some
  jurisdictions; either way, you may use these sample images freely.
- Marketplace disclosure: These assets are declared as
  **generative-AI-created content** on the Fab listing, per Fab policy.

## Audio

None. The sample contains no BGM, SE, or voice files.

## Fonts

Bundled since 2026-10-02 (outside `Game/`, in `Plugins/MomijiUI/Resources/Fonts/`):

- **BIZ UDPGothic** Regular / Bold and **BIZ UDPMincho** Regular / Bold
  (Morisawa Inc., via the Google Fonts repositories
  `googlefonts/morisawa-biz-ud-gothic` and `googlefonts/morisawa-biz-ud-mincho`).
- License: **SIL Open Font License 1.1**. The license texts are shipped next
  to the font files (`OFL-BIZ-UDGothic.txt`, `OFL-BIZ-UDMincho.txt`) and are
  copied into the packaged game as loose files. The fonts are redistributed
  unmodified; the Reserved Font Names are not used for any derived font.
- **Yomogi** Regular (Satsuyako) and **DotGothic16** Regular (Fontworks Inc.),
  via the Google Fonts repository `google/fonts` (added 2026-10-12, used by
  the RPG screen themes `sketch` and `dust`). SIL Open Font License 1.1;
  license texts `OFL-Yomogi.txt` and `OFL-DotGothic16.txt` are shipped
  alongside, fonts redistributed unmodified.
- Text is rendered only with these fonts; OS fonts are no longer used.
